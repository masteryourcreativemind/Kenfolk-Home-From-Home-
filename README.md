# Kenfolk-Home-From-Home-

**Pinewood / The Cabin Writer** is a directly playable browser survival game:
explore a village, fish, hunt, trade with NPCs, manage clothing and weather,
and care for a 1,000-HP body with individual organs. Research and write books
that download as EPUB/PDF bundles. The original autonomous AI writer is
also available.

```bash
cd cabin-writer-sim
python3 main.py
```

Open **http://127.0.0.1:8765**. No third-party packages are needed.
Use WASD or arrow keys to move, E to interact and M for the map.
See [the game guide](cabin-writer-sim/README.md) for controls and survival rules.
